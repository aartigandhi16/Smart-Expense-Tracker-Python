# Smart-Expense-Tracker-Python
A Python Tkinter-based Expense Tracker with CSV storage, expense summary, search functionality, validation, and exception handling.

# 💰 Smart Expense Tracker

A desktop-based Expense Tracker application built using Python and Tkinter.

## 🚀 Features

- Add new expenses
- View all saved expenses
- Search expenses by category
- Clear search field
- Calculate expense summary
- Automatic date tracking
- CSV file storage
- Input validation
- Exception handling
- User-friendly GUI

## 🛠️ Technologies Used

- Python
- Tkinter
- CSV Module
- Datetime Module

## 📸 Application Features

### Add Expense
Users can add:
- Amount
- Category
- Description

### View Expenses
Displays all saved expenses.

### Search Expense
Search expenses using category names.

### Expense Summary
Shows:
- Total number of expenses
- Total expense amount
